# ONE PIECE: Великий Путь

Фанатская action-RPG по вселенной One Piece в **одном файле Python**.
Вся графика, музыка и звуки генерируются кодом — внешних ассетов нет.

## Запуск

```bash
pip install pygame-ce numpy
python3 one_piece_grand_voyage.py
```

Нужен Python 3.10+ (проверено на 3.11). При первом запуске оркестр «записывает»
саундтрек (~30 секунд), дальше музыка берётся из кэша `~/.onepiece_grand_voyage/`.
Там же лежит сохранение `save.json`.

## Что внутри

- **4 пути**: Пират (награда за голову), Морской Дозор (звания от рядового до Адмирала Флота),
  Революционер (влияние), Охотник за головами (репутация, Кросс Гильдия).
- **7 рас** (человек, рыбочеловек, минк, небесный житель, длинноногий, лунариец, полувеликан)
  и 5 черт (включая «Качества Короля» для Королевского Хаки).
- **38 канонных дьявольских фруктов** — от Бара Бара до Гому Гому (Ника), Гура Гура, Ями Ями,
  Уо Уо (Сэйрю), Нидхёгг. У каждого своя прокачка мастерства и **пробуждение**.
- **13 стилей боя**: Санторю, Чёрная Нога, Рокусики, Карате рыболюдей, Рюо, Кулак Любви, Окама Кэмпо,
  Электро, Клима-Такт и другие; учатся у наставников (Зефф, Рэйли, Михоук, Джинбэй, Хьёгоро, Гарп…).
- **Хаки трёх видов**: Вооружение → Рюо, Наблюдение → Предвидение будущего, Королевское → покрытие.
- **Все арки до Эльбафа**: 30 сюжетных островов + Курайгана, Штаб Дозора, Момоиро, Карай Бари,
  Хатиносу, остров Шанкса. 86 боссов с фазами и катсценами.
- **Бои**: комбо, заряженные удары, парирование, идеальное уклонение, аниме-врезки ультимейтов,
  импакт-кадры, **столкновение ультимейтов**, логия неуязвима без хаки (или воды/стихии-противовеса),
  фруктовики тонут.
- **Разрушения**: здания рушатся от ударов и отброшенных врагов, огонь распространяется,
  лёд замораживает даже море, магма плавит землю. Пробуждённая логия выжигает остров дотла.
- **Корабль**: ветер и паруса, бортовые залпы, Coup de Burst, Гаон-пушка, морские короли в Затишье,
  штормы, водовороты, абордаж, рыбалка, Бастер Колл, 5 классов кораблей и улучшения у корабелов.
- Снаряжение с грейдами мечей (Вадзамоно → Сайдзё О Вадзамоно), кузница до +10 и именной клинок,
  команда (штурман, кок, врач, плотник…), канонные спутники в бою, Колизей Корриды, доска розыска.

## Управление

| Остров | |
|---|---|
| WASD / мышь | движение / прицел |
| ЛКМ / ПКМ (держать) | комбо / заряженный удар |
| Space / Shift | рывок (вовремя — идеальное уклонение) / блок (вовремя — парирование) |
| 1–4, R, F | приёмы, ультимейт, пробуждение |
| Q / C / Z | Хаки Вооружения / Наблюдения / Королевское |
| X / E / Tab | еда / взаимодействие / меню |

| Море | |
|---|---|
| W/S, A/D | паруса, руль |
| ЛКМ / ПКМ | бортовой залп / Гаон-пушка |
| Space / Shift | Coup de Burst / якорь |
| E / F / M | высадка, абордаж / рыбалка / карта мира |

F11 — полный экран.
