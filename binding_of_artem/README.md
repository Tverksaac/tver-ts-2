# СВЯЗЫВАНИЕ АРТЁМА (The Binding of Artem)

Рогалик в духе The Binding of Isaac по сюжету про Артёма, Костяна, Валерия,
Дымка, Серёгу Головко, Иисуса, Эллен Джо, Гастера и Даниила Митрофанова.

## Запуск

```
python binding_of_artem.py
```

Нужен Python 3.8+. Библиотеки `pygame` и `numpy` скрипт поставит сам через pip
(или вручную: `pip install pygame numpy`).

Вся графика и вся музыка генерируются кодом — никаких внешних файлов.
При первом запуске музыка «сочиняется» в фоне (~15 сек) и кешируется в
`~/.binding_of_artem/music_cache`. Там же лежит сохранение (`save.json`):
открытые концовки, персонажи и смерти от Костяна.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Стрелки | стрельба |
| Пробел | активный предмет |
| E / Shift | бомба |
| Enter | поговорить |
| Tab | карта и статы |
| Esc | пауза |
| M / F11 | музыка / полный экран |

В диалогах: W/S или стрелки — выбор, Enter — далее, X — промотать.

## Что внутри

* Этажи как в Айзеке: Квартира → Рай → Школа №52 → Лёгкие Серёги → Рай → Тёмная квартира,
  дальше — Небесный престол, Дом, Домейн Костяна и Пустота.
* Сокровищницы, магазины, секретные комнаты (ищи трещины в стенах и взрывай бомбой),
  ключи, монеты, бомбы, сердца, души, батарейки, ~55 предметов с синергиями,
  активные предметы и 3 трансформации (Серафим, Дымок, Мастер Подземелий).
* Боссы: Валерий (2 раза), Гробница Царапаний Дымка, Табачное облако, раки,
  Последний рак, Иисус, Костян (уклоняется от всего) и его дух Таск.
* Пермасмерть как в Айзеке. Исключение — Костян: он помнит каждую твою смерть.
* 12 концовок (нейтральная, пацифист, их истинные версии, геноцид и его развязки, шуточные).
* 3 персонажа (двое открываются концовками).
